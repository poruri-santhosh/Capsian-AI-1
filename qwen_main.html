Variables

Variables are containers for storing data values. You can think of them as labeled boxes that hold information your program can use and change.

Example
let name = "Helix";
let age = 28;
Visual Model

Each variable has a name (the label) and a value (what's inside). When you use let, you're creating a new labeled box.
